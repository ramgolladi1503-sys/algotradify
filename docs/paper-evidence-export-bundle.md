# Paper Evidence Export Bundle

PR 96 adds a deterministic local paper evidence export bundle.

## Purpose

Paper evidence can now be generated by scenarios and persisted locally. This bundle layer packages that evidence into a portable, reviewable local folder for later replay and research work.

This PR does not create replay datasets, compute expectancy, add dashboards, expose APIs, wire runtime, call brokers, or touch live behavior.

## Bundle layout

```text
bundle_root/
  manifest.json
  checksums.json
  evidence/
    paper_evidence.jsonl
  scenarios/
    scenario_results.json
```

## Manifest fields

```text
schema_version
bundle_type
bundle_id
created_at_epoch
source_evidence_path
record_count
scenario_count
files
checksums
safe_flags
paper_only
read_only
is_order_action
broker_api_called
real_order_id
```

## Core operations

```text
build_paper_export_bundle
validate_paper_export_bundle
load_paper_export_manifest
stable_file_hash
```

## Safety contract

Every bundle result and manifest exposes:

```text
paper_only=true
read_only=true
is_order_action=false
broker_api_called=false
real_order_id=null
```

## Blocking behavior

The bundle layer fails closed on:

```text
missing bundle root
missing evidence path
blocked persistence load
corrupt evidence file
unsafe evidence flags
unsafe scenario result flags
missing manifest
missing checksums
missing expected bundle file
checksum mismatch
unknown bundle schema version
forbidden replay dataset output
forbidden expectancy/profitability output
```

## Scope boundary

This PR does not add:

```text
replay dataset generation
expectancy/profitability validation
runtime wiring
API
UI/dashboard
broker execution
LIVE execution
new strategies
ML/ranker work
cloud upload
```
